# DSH 桌宠

将 Codex / ChatGPT 桌面 Pet 的核心桌面体验接到本机 DSH，并继续使用 DSH 已有的蓝发小女仆形象。桌宠是透明悬浮角色和轻量控制条，不另做聊天或任务管理页面。

## 已接入的体验

- 角色可拖动并保存位置。**静止态默认只有角色 + 一条 26×6px 的短白色圆角小条**，没有胶囊、按钮或徽章；鼠标移到角色 / 小条上才淡入完整玻璃胶囊，移开后淡出回小条。给动画头顶留出净空。
- **收起态稳定且持久**：3.5s 轮询、新通知、会话状态切换、首次唤醒都不会把胶囊或活动卡片自动弹出来；启动时强制回到收起态并把偏好写入本地，重启桌宠后仍是安静的小条。点击角色或报错提示只把胶囊短暂固定 6 秒，不摊开活动列表。
- **胶囊浮现后有两种形态（对齐 Codex Pet）**：通知收起态（Form B）为撰写 / 声波 / 铃铛，铃铛带白色圆形底和绿色未读数字徽章；点开通知后（Form A）铃铛换成向下 chevron、徽章隐藏，胶囊下方出现一条约 340px 宽、26px 圆角的全宽玻璃横幅（圆形状态图标 + 粗体标题 + 两行灰色副标题）。两态都只有一条位于撰写与声波之间的 16px 竖直细分隔线；撰写图标按 `square.and.pencil` 的「右上角开口圆角方框 + 细长空心斜铅笔」重画。
- **通知横幅分两层（对齐 Codex）**：折叠态是全圆角胶囊，只有粗体标题 + 一行灰色副标题，状态圆点、动作按钮、进度条都不显示；宿主返回的 `429: {"message":...}` 原始错误会精简成「429: 您的使用量已超出频率限制」这类短句。鼠标悬停或展开详情后，状态圆点、完整错误文本和「打开 / 展开 / 回复 / 静音 / 关闭」动作才回来，功能不丢失。
- **工作态**：会话 `running` 时小条只**变绿并轻微呼吸**，胶囊依旧不出现，角色同步切到 DSH 忙碌动画；不会像旧版那样把整个控制条撤掉换成绿条。主动展开面板时胶囊仍可见，方便随时停止或追问。新通知到达只刷新铃铛计数，不破坏收起态。
- 撰写按钮展开快速聊天。输入后回车发送任务，并记住这个快速聊天会话，之后可「恢复快速聊天」继续追问，或点「新聊天」重开；新会话使用 `quickChatCwd` 指定的本地工作目录。
- 快速聊天记录（transcript）可查看最近消息、引用某条消息回复、移除引用、返回紧凑条；发送失败可在提示条里重试。
- 「+ 添加上下文」提供：最多 5 张图片附件、`/` 技能目录、`@` 文件引用搜索、模型切换。技能与文件目录分别读 DSH 的 `sessionSkillCatalog` 和 `sessionFileReferences`，模型读 `modelCatalog` / `selectModel`。
- 声波按钮在宿主提供语音识别服务时启动分段语音对话：每段最长 24 秒，由 DSH 已配置的语音识别转成文字；DSH 回复后用系统语音播报，并自动开始下一段聆听。首次使用时由系统请求麦克风权限。宿主未配置识别服务时按钮仍保留以对齐 Codex 外观，点击只给出「语音功能未接入」提示。
- 铃铛 / chevron 在两种形态间切换：展开显示所有待关注活动，再点一次收起活动列表但保留控制条；列表可滚动，点击活动回到对应 DSH 会话。超过三条可折叠成通知栈。每张卡片悬停或展开后有打开、回复、停止、静音 / 取消静音、关闭等动作；回复直接在卡片内联输入并沿用原会话。
- 状态标签与副标题按 Codex Pet 分类：需要输入 / 已完成 / 正在思考 / 受阻；运行中的工具区分「正在编辑文件 / 正在运行命令 / 正在搜索网页 / 正在调用 X」，完成后对应「已…」。待审批卡片显示真实工具名与原因，并提供「在 DSH 中处理」入口。
- 首次使用显示一次「Hi, I'm 蓝发小女仆」引导；静音、手动关闭、已读状态、快速聊天会话与模型选择保存在本地，重启桌宠后仍生效。
- 活动按待确认、受阻、未读完成、运行中排序；各会话分别跟踪新活动，因此一个会话正在等待确认时，其他会话完成也会触发提醒。角色使用最高优先级会话的真实状态动画。运行中的真实待办会显示已完成项数和进度条；没有待办数据时只显示动态状态条，不编造百分比。对齐 Codex 的 Form A 横幅时，折叠态不显示进度条；进度条只在展开详情里出现。
- 全局快捷键显示桌宠并聚焦快速聊天；托盘菜单和 DSH 设置可显示 / 隐藏、调整桌宠大小、仅显示控制条和重置位置。大小有 70%–120% 六档；仅显示控制条和尺寸互不覆盖。
- 遵循系统“减少动态效果”设置。

桌宠通过受令牌保护的本机桥接调用 DSH 的 `SessionController`。认证信息只保存在桌面主进程；网页预览不持有该凭据。

## 与 Codex Pet 的边界

核心桌面流程已对应到 DSH：新建 / 恢复聊天、聊天记录与引用回复、添加上下文、活动提醒与通知动作、展开 / 收起活动、状态动画、拖动、尺寸调整和仅控制条模式。以下差异来自 DSH 当前提供的数据、接口和平台能力，不是 CSS 能补的：

- **审批不能在桌宠内批准**。DSH 的审批由 Host 内同进程 waterfall（`approval/request`）当场决定，客户端 UI 是同进程应答者；桌宠是独立进程、靠轮询取状态，等卡片出现时决策已经结束。强行注册应答者会抢走 DSH 主界面的审批权。因此桌宠只展示真实工具名 / 原因并跳转 DSH，不提供 Allow / Allow once / Allow network / Deny 按钮。
- **`@` 与 `/` 是文本标记，不是完整上下文对象**。目录来自 DSH 的技能与文件引用服务；文件引用只对已经激活的 Agent 可用，且不会为了让补全出现而冷启动一个会话。Appshots、屏幕截图、`uploadFile` 文件回执尚未接入；图片附件走 `prompt` 的 `image` 内容，最多 5 张，`file` 类型暂不支持。
- **语音**采用 DSH 配置的识别服务加系统语音播报，按段往返，和 Codex 的实时双向语音流仍有差异。
- **进度**只能按 DSH 实际发出的待办项展示，没有连续百分比、`+/-` 行数或 patch 文件计数来源；这些数字不会伪造。
- **原生玻璃**：Codex 用 `NSVisualEffectView`（`data-owl-native-glass`），Electron 透明窗口只能用 `rgba + backdrop-filter` 近似，不会模糊窗口外的桌面内容。
- **角色与身份**：DSH 沿用 640×360 WebM 的蓝发小女仆素材，命中框比例与 Codex 的 192/208 不同；Codex 蓝色机器人面罩的 `>_` / `⌒⌒` 表情是其专有形象，DSH 不临摹，状态改由 5 套 WebM 动画、铃铛绿色计数和工作态绿条表达。pet 命名、挑选 / 自定义形象、首次唤醒状态绑定 Codex 账号体系，DSH 只绑定本机配置。
- **玻璃透明度**：收起态胶囊白底降到 `rgba(255,255,255,.44)` 并给图标加白色光晕，让桌面纹理透出；但 Codex 的 `NSVisualEffectView` 还会磨砂模糊背景，Electron 做不到，深色壁纸上图标对比度仍低于原生。
- **图标资源**：Codex 使用 SF Symbol（如 `square.and.pencil`）原生矢量图标；DSH 用自绘 SVG 近似描摹，描边粗细和光学重心仍可能有细微差别，不是同一套图标资源。
- **设置入口**：Codex 在设置页提供尺寸、可见性（alwaysVisible / onDemand）与形象，profile 菜单 Hide / Show Pet；DSH 在 DSH 设置页与托盘菜单提供显示 / 隐藏、六档尺寸、仅控制条、重置位置。语义相近但不完全一致。

插件绑定本机 DSH 配置和运行服务，不绑定 Codex 账号。桌宠位置与偏好保存在 `~/.dsh/companion/`。插件 id 为 `companion`，包名为 `dsh-companion`，配置入口位于 DSH 设置左侧“DSH 桌宠”。

## 验证

`npm run check` 检查 JavaScript 语法；`npm test` 检查本机桥鉴权、会话状态、创建与发送、语音 WAV 验证、导航和显示器边缘定位。浏览器预览只能核对外观和 Web 交互。原生 Electron 桌面中的麦克风系统授权、快速任务、活动提醒、全局快捷键及多屏拖动需要在启动 DSH 后实测；不能仅凭测试或浏览器预览宣称完成原生验收。

## 停用

仅移除 `~/.dsh/profiles/web/package.json` 中 `dsh.profile.bundles` 和 `dependencies` 的 `dsh-companion` 项，再重启 DSH。不要删除原有桌宠素材或覆盖整个 DSH 配置。聊天记录不随插件移除。
